# TiO₂ Photocatalytic Degradation Analyzer — web

Браузерная версия настольного анализатора фотокаталитической деградации красителя на TiO₂.
Всё считается на клиенте: фото никуда не отправляются.

- A = −log₁₀(I/I₀), I₀ — 95-й перцентиль яркости foreground
- автопорог Otsu по OD, маска и детекция пятна
- кинетика 1-го порядка: ln(⟨A⟩(t)/⟨A⟩(0)) = −k·t, t½ = ln2/k
- каналы: яркость, длина волны (λ → R/G/B), насыщенность

Демо-эксперименты сгенерированы по закону Бугера—Ламберта—Бера. Свои фото — кнопка «Добавить фотографии» или перетаскивание.


## Интерфейс

Адаптивная светлая рабочая область TiO₂ Lab: крупные элементы управления на телефоне,
переключение оригинала, маски и детекции, карточки k и t½, легенда графика и сравнение
экспериментов. На узком экране таблица становится карточками. Демо явно помечены
как синтетические данные. Кнопка «Переименовать» доступна и на телефоне;
на клавиатуре вкладки переключаются стрелками, Home и End.

Откройте `index.html` или запустите `python3 -m http.server 8793` и перейдите
на `http://localhost:8793`. Сборка и внешние зависимости не нужны.
GitHub Pages публикует корень ветки `main`.

Редизайн не изменяет расчётное ядро `core.js`. Фотографии и эксперименты остаются
в памяти вкладки и не сохраняются после перезагрузки.

## Условия измерения

Нормировка по I₀ и начальному значению уменьшает влияние ряда различий в съёмке,
но не гарантирует независимость от камеры. Нужны стабильное освещение, неизменный
ракурс и настройки, отсутствие пересвета и достаточный сигнал. I₀ сейчас оценивается
по 95-му перцентилю переднего плана, а не по отдельному калиброванному эталону.
Выбор λ переключает RGB-канал; камера не выполняет спектральное измерение.
